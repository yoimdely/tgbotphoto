# Telegram-бот для подготовки фото объявлений

Бот на **aiogram 3** умеет скачивать фотографии и описание объявлений с **Авито**, **Циан** и **Домклик**, убирать водяные знаки, улучшать и отзеркаливать изображения, а также собирать их в ZIP-архив.

## Требования
- Python 3.10+
- Установленные зависимости из `requirements.txt`

## Настройка
1. Скопируйте `.env.example` в `.env` и заполните значения:
   ```env
   BOT_TOKEN=your_bot_token_here
   ADMIN_IDS=[123456789]
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите бота:
   ```bash
   python main.py
   ```

## Возможности
- Парсинг объявлений Avito/Циан/Домклик, загрузка описания и всех фото.
- Очистка водяных знаков, улучшение качества и отзеркаливание по кнопке.
- Скачивание подготовленных изображений ZIP-архивом.
- История последних запросов с возможностью повторной обработки.
- Простые лимиты по тарифам и заготовка для эквайринга.
- Базовая админ-статистика.
