# Telegram бот для очистки фото объявлений

Бот на aiogram 3 умеет скачивать фотографии и описание объявлений с Авито, Циан и Домклик, удалять водяные знаки, улучшать качество и отзеркаливать изображения.

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе `.env.example` и укажите токен бота.
3. Запустите:
   ```bash
   python main.py
   ```

## Возможности
- Очистка водяных знаков и отправка альбомов.
- Улучшение, отзеркаливание и загрузка фото архивом по кнопке.
- Лимиты по тарифам и заготовка эквайринга.
- История последних запросов и простая админ-статистика.
